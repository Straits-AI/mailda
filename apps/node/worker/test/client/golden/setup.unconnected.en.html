Setup

This Node holds no Cloudflare credential of its own.

0 of 4 steps done; next: an address to receive at. The fifth is optional.

  1. to do An address to receive at no address is configured; add one on People
  2. to do Mail routed to this Node not set up; the installer or the Setup screen does it
  3. to do A domain onboarded for sending not set up; the installer or the Setup screen does it
  4. to do Delivery outcomes observed not set up; the installer or the Setup screen does it
  5. optional Connected to Cloudflare only for changing the Cloudflare setup from this screen

Receiving, sending and delivery outcomes are set up at install, with the consent wrangler already had, or later with mailda setup. Connecting this Node, below, is what lets you change them from this screen.

Optional: connect this Node to Cloudflare from this screen

The install set receiving, sending and delivery outcomes up with the consent wrangler already had, so this Node works without a credential of its own. Connecting it is only for changing that from here: another receiving domain, a sending domain, taking over a routing rule.

Create one API token in Cloudflare with exactly these permissions, restricted to this account, and paste it below. This Node holds it wrapped under its credential key and never shows it again.

The 2 permissions the token needs, and why
Permission Scope What this Node does with it
Zone Read zone find the zone a domain lives in
Registrar Domains Read account price a domain before buying it Optional.

The permission names come from Cloudflare's token form and are not measured against it.
